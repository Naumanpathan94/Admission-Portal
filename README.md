# WATERMENON UNIVERSITY Website

## Project Description
This project is a responsive and visually appealing website for WATERMENON UNIVERSITY. It serves as the official online presence of the university, providing information about campus events, courses offered, application procedures, and contact details. The website aims to welcome prospective students and provide them with all necessary information to join the university.

## Features
- Home page with a welcoming banner and university introduction
- Campus events section showcasing upcoming events and specialities
- Application section for Bachelor and Masters degree programs
- Popular courses listing with ratings and descriptions
- University facts and statistics to highlight achievements and scale
- Contact form for inquiries with phone, email, and address details
- Responsive design with smooth scrolling navigation
- Integration of multimedia including images and video links
- Social media icons for Facebook, Twitter, Behance, and LinkedIn

## Technologies Used
- HTML5 and CSS3
- Bootstrap 4 for responsive layout and components
- jQuery for DOM manipulation and event handling
- FontAwesome for icons
- Owl Carousel for sliders and carousels
- Lightbox for image viewing
- Custom JavaScript for interactive features

## How to Run Locally
1. Clone or download the repository to your local machine.
2. Navigate to the `edu-meeting/edu-meeting/edu-meeting/` directory.
3. Open the `index.html` file in your preferred web browser.
4. The website should load with full functionality and styling.
